# Resultados del proyecto

Esta carpeta contiene el informe final:

- [`proyecto_steam_resumido.pdf`](proyecto_steam_resumido.pdf): documento que presenta los datos, la metodología, las estimaciones, los casos y las limitaciones del estudio.

La fuente reproducible del informe está en [`cod/proyecto_steam_resumido.qmd`](../cod/proyecto_steam_resumido.qmd). Las instrucciones de ejecución y dependencias se encuentran en [cod/README.md](../cod/README.md).

También existe una copia del PDF en [`docs/informe.pdf`](../docs/informe.pdf), usada por el enlace y el QR de la presentación. Generar nuevamente el PDF en `res/` **no actualiza automáticamente** esa copia. Si se decide publicar una nueva versión, comprueba el PDF generado y actualiza ambas copias de forma deliberada.
