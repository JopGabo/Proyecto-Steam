# Recursos de la presentación

Esta carpeta contiene los archivos que utiliza la presentación de [`docs/`](../). Conserva las rutas y los nombres de archivo para que `index.html` pueda encontrarlos.

## Gráficos y QR

- `kaplan-meier.png`: curvas de Kaplan–Meier reconstruidas a partir del análisis del proyecto.
- `trayectorias.png`: trayectorias relativas de *Crush Crush* y *Terraria*.
- `qr-informe.png`: código QR para abrir el [informe PDF publicado](https://jopgabo.github.io/Proyecto-Steam/informe.pdf).

Los dos gráficos se incluyen para que la presentación funcione sin conexión. Consulta [docs/README.md](../README.md) antes de intentar regenerarlos: el script necesita una adaptación de ruta en la estructura actual del repositorio.

## Imágenes y créditos

- `steam-logo.svg`: identidad de Steam; [recursos y guía de marca de Valve](https://partner.steamgames.com/doc/marketing/branding?language=english).
- `crush-crush.jpg`: [portada de Crush Crush en Steam](https://store.steampowered.com/app/459820/Crush_Crush/).
- `terraria.jpg`: [portada de Terraria en Steam](https://store.steampowered.com/app/105600/Terraria/).
- `portal2.jpg`, `stardew.jpg` y `hollowknight.jpg`: portadas ilustrativas de [Portal 2](https://store.steampowered.com/app/620/Portal_2/), [Stardew Valley](https://store.steampowered.com/app/413150/Stardew_Valley/) y [Hollow Knight](https://store.steampowered.com/app/367520/Hollow_Knight/). No corresponden a casos individuales del análisis.
- `journey-end.png`: ilustración de un [anuncio oficial de Terraria en Steam](https://store.steampowered.com/news/app/105600/view/2205019689483334899).

Las marcas y las imágenes pertenecen a sus respectivos titulares. Su presencia en este proyecto no implica afiliación ni patrocinio.
